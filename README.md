# Galaxy Multi-Account Switcher

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Tampermonkey](https://img.shields.io/badge/Tampermonkey-userscript-blue)](https://www.tampermonkey.net/)

Userscript для сайта [galaxy.mobstudio.ru](https://galaxy.mobstudio.ru/web/) — добавляет плавающую панель со **всеми** аккаунтами из cookie `client`, включая те, что не попадают в нативный список из-за лимита в 3 аккаунта.

![Image](/preview/image.png)

---

## ✨ Возможности

- 📋 Показывает **все** аккаунты, сохранённые в cookie `client`, а не только топ-3
- 🔄 Переключение между аккаунтами в один клик
- 🎯 Автоматически поднимает `sortOrder` выбранного аккаунта, чтобы он попал в нативный топ-3 (иначе сайт его игнорирует)
- ✅ Отмечает галочкой аккаунты, видимые в нативном списке
- 🎨 Активный аккаунт выделяется зелёным
- 🖱️ Панель можно закрыть крестиком
- 🔁 Следит за изменениями cookie — если переключиться штатным способом, панель обновится

---

## 🚨 Решаемая проблема

Веб-клиент Galaxy хранит в cookie `client` структуру:

```json
{
  "users": {
    "_id": 12345678,
    "byId": {
      "11111111": { "nick": "Ник",   "sortOrder": 2, ... },
      "22222222": { "nick": "Никита",  "sortOrder": 4, ... },
      "33333333": { "nick": "Никитос",  "sortOrder": 3, ... },
      "44444444": { "nick": "Никусик",    "sortOrder": 1, ... }
    }
  }
}
```

При загрузке главной страницы клиент сортирует аккаунты по `sortOrder` (по убыванию) и **отображает только первые 3**. Четвёртый аккаунт остаётся в cookie, но в UI не попадает. При этом листать список нельзя — это жёсткий лимит фронтенда.

**Скрипт решает это так:** при клике на аккаунт в панели он ставит этому аккаунту `sortOrder` выше всех остальных. После перезагрузки аккаунт гарантированно попадает в топ-3 и становится доступен для нативного переключения без перезагрузки.

### 1. Установите Tampermonkey

| Браузер | Ссылка                                                                                                          |

| Chrome  | [Chrome Web Store](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)     |

| Safari  | [App Store](https://apps.apple.com/app/tampermonkey/id1482490089)                                               |

### 2. Разрешите пользовательские скрипты

**Chrome / Edge (обязательно!):**
1. Откройте `chrome://extensions/` (или `edge://extensions/`)
2. Найдите Tampermonkey → **Детали**
3. Включите тумблер **«Разрешить пользовательские скрипты»**

> ⚠️ Без этого шага скрипт не запустится, а Tampermonkey будет показывать предупреждение «Пожалуйста, включите настройку "Разрешить пользовательские скрипты"».

### 3. Установите userscript

**Способ A — через ссылку (рекомендуется):**
- Откройте в браузере: `https://raw.githubusercontent.com/unrie/galaxy-account-switcher/main/galaxy-account-switcher.user.js`
- Tampermonkey предложит установку → **Установить**

**Способ B — вручную:**
1. Кликните по иконке Tampermonkey → **Создать новый скрипт**
2. Удалите шаблон, вставьте содержимое `galaxy-account-switcher.user.js`
3. **Ctrl+S** для сохранения

### 4. Готово

Откройте [galaxy.mobstudio.ru/web/](https://galaxy.mobstudio.ru/web/) — в **левом нижнем углу** появится панель со всеми аккаунтами.

## 🎮 Использование

- **○ Ник** — кликните, чтобы переключиться. Страница перезагрузится, и выбранный аккаунт станет активным и попадёт в нативный топ-3.
- **● Ник** (зелёный) — текущий активный аккаунт.
- **✓** — аккаунт виден в нативном списке (топ-3 по `sortOrder`).
- **✕** — закрыть панель.

После переключения через панель выбранный аккаунт появится в штатном списке, и дальше можно переключаться между тремя «нативными» без перезагрузки.

---

## ⚙️ Как это работает

1. Userscript читает cookie `client` и парсит JSON.
2. Строит плавающую панель со всеми аккаунтами из `users.byId`, отсортированными по `sortOrder`.
3. При клике на аккаунт:
   - Находит текущий максимальный `sortOrder`
   - Устанавливает выбранному `sortOrder = max + 1`
   - Меняет `users._id` на ID выбранного
   - Сохраняет cookie и вызывает `location.reload()`
4. После перезагрузки сайт читает cookie, видит новый `_id` и аккаунт с самым высоким `sortOrder` — и отображает его в нативном списке первым.

---

## ⚠️ Ограничения

- Нативный список **всегда вмещает только 3 аккаунта** — это фронтенд-лимит, а не серверный. Обойти его без вмешательства в JS-бандл приложения невозможно.
- Переключение через панель требует перезагрузки страницы (~1–2 сек). Это связано с тем, что внутренний стор приложения находится в замыкании и недоступен извне.
- Скрипт может перестать работать, если разработчики изменят структуру cookie `client` или механизм сортировки.

## 🧪 Отладка

Если панель не появляется:

1. **Проверьте, что Tampermonkey включён** и разрешены пользовательские скрипты (см. шаг 2 установки).
2. Откройте **F12 → Console** и выполните:
   ```js
   document.getElementById('galaxy-acc-panel')  // должна вернуть div
   document.cookie.includes('client=')           // должно быть true
   ```
3. Проверьте **Errors** в панели управления Tampermonkey на вкладке скрипта.
4. Убедитесь, что вы находитесь именно на `galaxy.mobstudio.ru/web/*` (а не на другом поддомене или пути).

## 🛠️ Разработка

1. Внесите изменения в файл.
2. В Tampermonkey: **Утилиты → File → Import** — импортируйте обновлённый файл.
